# 可以直接对 AI 说的话

Claude Code 用 `/feishu-call …` 开头，Codex 用 `Use $feishu-call …` 开头；不写开头、直接贴飞书链接，AI 一般也会自己用上这个 skill。尖括号里换成你的内容。

## 读多维表格

```text
/feishu-call 读一下这个多维表格，按「负责人」汇总未完成的记录数：
<多维表格链接>
```

## 写回多维表格

```text
/feishu-call 把下面这几行追加到这个多维表格，字段名一一对应；写完读回来给我核对：
<多维表格链接>
<粘贴要写入的行>
```

## 读电子表格

```text
/feishu-call 读这个表格的「<sheet 名>」页，找出 <列名> 为空的行：
<电子表格链接>
```

## 读文档或 Wiki

```text
/feishu-call 读这篇文档，整理成 5 条要点：
<文档或 Wiki 链接>
```

## 更新文档的一部分

```text
/feishu-call 把这篇文档里「<小节标题>」这一节换成下面的内容，其他部分不动；先给我看要改的地方：
<文档链接>
<新内容>
```

## 发消息

```text
/feishu-call 给 <群名或同事名> 发一条消息：<消息内容>。发之前先给我看一眼。
```

## 日程

```text
/feishu-call 帮我在 <日期> <时间> 建一个 30 分钟的日程「<标题>」，邀请 <同事名>。
```

## 查自己的待办

```text
/feishu-call 列出我飞书任务里本周到期、还没完成的任务。
```

## 登录出问题时

```text
/feishu-call 检查一下飞书登录状态，失效了就按 skill 的流程恢复。
```
